# 🎯 Curso C# Essencial — .NET 9.0, LINQ e IA
Repositório criado para documentar minha evolução durante o **Curso C# Essencial (.NET 9.0, LINQ e IA)**, ministrado por **Macoratti**.

O projeto reúne exercícios, exemplos práticos e aplicações desenvolvidas ao longo dos estudos, com foco no fortalecimento dos fundamentos de **C#**, **.NET**, **LINQ**, **Programação Orientada a Objetos** e no uso de **Inteligência Artificial como ferramenta de apoio ao desenvolvimento**.

---

## 📌 Sobre o projeto

Este repositório faz parte da minha preparação para atuar profissionalmente como **Desenvolvedor .NET**.

Durante o curso, os conceitos são aplicados por meio de exercícios práticos e pequenos projetos, buscando não apenas compreender a sintaxe da linguagem, mas também desenvolver uma base sólida para construção de aplicações reais.

### Principais objetivos

* Aprimorar os fundamentos de C#;
* Desenvolver aplicações utilizando .NET 9.0;
* Consolidar conceitos de Programação Orientada a Objetos;
* Trabalhar com Collections e Generics;
* Utilizar LINQ para consulta e manipulação de dados;
* Aplicar tratamento de exceções;
* Desenvolver código organizado e legível;
* Conhecer recursos modernos da plataforma .NET;
* Explorar o uso de IA como ferramenta de produtividade no desenvolvimento.
